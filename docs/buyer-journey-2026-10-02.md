# Buyer journey and country atlas — 2 October 2026

- One header/mobile account entry; login and registration switch within the same account page, preserving the return destination.
- `/decrire-mon-besoin` and `/demande-de-devis` provide a bilingual four-step brief: technical specifications, multiple line items, quantities, recurring volume, samples/budget, delivery dates/country, packaging, quality and documentation requirements.
- Drafts are validated and kept in sessionStorage for this tab, with text export available before authentication. Server saving uses existing authenticated `buyer_company`/`save_rfq` workflows, permissions and idempotency keys. No supplier is contacted by this form. Existing product-specific requests retain their preselected-product workflow.
- `/pays`: restrained world atlas with regional transitions (disabled for reduced motion), zoom, clickable outlines and searchable index of all 249 ISO countries/territories. Catalogue filters now expose all of them. API errors are distinct from zero matching suppliers. Supplier counts/cards come exclusively from public catalogue results filtered by production country; no illustrative supplier locations or network connections.
- Geography: Natural Earth 110m admin-0 GeoJSON, public domain, https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson . Projected equirectangular paths are in `lib/maps/world.json`; small territories remain accessible through the index. Terms: https://www.naturalearthdata.com/about/terms-of-use/ . Video unchanged.

Validation: TypeScript, targeted ESLint, production build, `node scripts/test-requirement.mjs` (required fields, decimal/invalid quantities, date ordering, all fields retained in bilingual serialization, restored-draft schema and backend size limit). Browser checks at desktop and 390px: account mode switch, Japan search/selection, two-item requirement, native date keyboard input, review, error handling, no horizontal overflow. Date-fill automation required a real keyboard event to commit the browser's native date control.

Environment limitation: catalogue/account APIs currently return unavailable in the deployed environment. Real account creation, database save, file upload and supplier transmission cannot be claimed as live-verified until the existing backend configuration is completed. Local draft preparation/export is independent of those services.
